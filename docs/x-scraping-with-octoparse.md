# Octoparse を使った X（旧 Twitter）情報収集 自動化手順書

無料のノーコード Web スクレイピングツール **Octoparse** に組み込まれている
**X（Twitter）専用テンプレート**を使って、X のポストデータを取得・エクスポートする
手順をまとめたものです。

参考記事：
[X（旧 Twitter）からデータをスクレイピング・取得する方法（Qiita / Octoparse Japan）](https://qiita.com/Octoparse_Japan/items/77d23518a22e0055d088)
元記事：
<https://www.octoparse.jp/blog/how-to-scrape-and-download-tweets-for-free>

## 0. はじめに：X データの主な活用方法

X には膨大なデータ（プロフィール・ハッシュタグ・タイムライン・投稿）が存在し、
スクレイピングしたデータは主に以下の用途で活用できます（参考記事より）。

1. **ブランドモニタリング** — 自社サービス名 + ネガティブワードで早期問題検知
2. **予測分析** — 「栗」「秋刀魚」など季節キーワードの出現時期から需要予測
3. **競合分析** — 競合アカウント・キャンペーンの監視
4. **センチメント分析** — NLP でポジ/ネガ/中立の感情判定
5. **機械学習モデル構築** — NLP・感情分析モデルの学習データ
6. **業界動向把握** — 新技術・トレンドの早期キャッチ
7. **市場調査** — リアルタイム消費者の声、地域別・時間別分析
8. **マーケティング最適化** — 投稿形式の効果比較、インフルエンサー特定
9. **製品イノベーション** — ユーザーフィードバックからの改善点抽出
10. **研究活用** — 社会科学・コンピュータサイエンスの研究データ

## 1. X からデータを取得する 3 つの方法

| 方法 | コスト | 難易度 | 自由度 | 適したシーン |
|---|---|---|---|---|
| **Web スクレイピングツール（Octoparse 等）** | 無料〜 | ★☆☆ | 中 | 初心者・小〜中規模の収集 |
| **X API v2** | $200/月〜（Basic）| ★★★ | 高 | 業務利用・規約遵守必須 |
| **OSS スクレイピングパッケージ** | 無料 | ★★☆ | 高 | エンジニアの自前運用 |

### 1-1. X API v2 のプラン（2024 年 11 月改定）

| プラン | 月額 | 月間投稿上限（ユーザー/月）| 月間取得上限 | App 数 | 主な機能 |
|---|---|---|---|---|---|
| Free | 無料 | 500 件 | 100 件 | 1 | 基本 API、自分のポスト関連のみ |
| Basic | $200 | 3,000 件（App あたり 50,000）| 15,000 件 | 2 | 他人のポスト・リアルタイム取得・DM 管理 |
| Pro | $5,000 | App あたり 300,000 件 | 1,000,000 件 | 3 | 大量データ・フィルタリングストリーム |
| Enterprise | カスタム | 制限なし | 制限なし | カスタム | フル API + サポート |

**Free プランでは他人のポスト・フォロワー情報は取得不可**。
本格運用は Basic 以上が前提となります。

### 1-2. API の Python サンプル（参考記事より）

```python
import os
from requests_oauthlib import OAuth1Session

consumer_key = os.environ['CONSUMER_KEY']
client_secret = os.environ['CLIENT_SECRET']
access_token = os.environ['ACCESS_TOKEN']
access_token_secret = os.environ['ACCESS_TOKEN_SECRET']

oauth = OAuth1Session(consumer_key, client_secret, access_token, access_token_secret)

def lambda_handler(event, context):
    text = "おはようございます！"
    payload = {'text': text}
    oauth.post("https://api.twitter.com/2/tweets", json=payload)
```

API 利用には「重複コンテンツポリシー」などの規約があり、違反すると一定時間
利用停止になります。

### 1-3. OSS パッケージ

無料で柔軟ですが、プログラミング知識が必須で、アップデート・バグ修正の
即時性は保証されません。また悪意ある第三者から狙われやすく、
不正アクセスや乗っ取りのリスクもあります。

## 2. 結論：初心者には Octoparse が最適

ノーコードでクリック操作だけで動作し、無料プランで個人利用には十分です。
わずか 10 分程で何千ものポストデータを抽出できます。
以降、Octoparse でのスクレイピング手順を解説します。

## 3. Octoparse でポストデータをスクレイピングする手順

Octoparse には **X 専用のテンプレート** が複数用意されており、
**カスタムタスクを自分で作らなくても** 動かせます。

### ステップ 1：Octoparse のダウンロードとログイン

1. <https://www.octoparse.jp/> から Windows / Mac 版をダウンロード。
2. インストールして起動、無料アカウントでログイン。
3. 起動後の画面の **検索窓に「Twitter」と入力**。

### ステップ 2：X 関連テンプレート一覧

検索すると以下のテンプレートが表示されます（参考記事より）。

| テンプレート名 | 機能 |
|---|---|
| **Get Twitter Cookies** | ユーザー名（@xxx）とパスワードを入力すると Cookie を取得。**他のテンプレートを使う前に必ず実行** する。 |
| **Twitter Scraper (by Account URL)** | アカウントページから、各ポストの投稿 ID・投稿内容・投稿日時など詳細情報を抽出。 |
| **Twitter Scraper (by Search Result URL)** | X 検索結果ページから、各ポストの投稿内容・投稿日時などを抽出。 |
| **Tweets & Comments Scraper (by Search Result URL)** | キーワード検索結果から、最新ポスト・トップポストなどを抽出。 |
| **Twitter Scraper (by hashtag)** | トップポストから「いいね数」「リポスト数」「返信数」などを抽出。 |
| **Twitter Scraper (by Keywords)** | 任意の期間・特定キーワードで投稿された情報を抽出。 |
| **Twitter Auteur Scraper** | キーワードから作成者情報（コンテンツ、コメント等）を抽出。 |

> **注意：「自分のホームタイムライン」「通知一覧」専用のテンプレートは存在しません。**
> 近い目的を達成するには、
> - **自分のアカウントURL** を `Twitter Scraper (by Account URL)` に入れて自分のポストを取得
> - **フォロー先個別アカウント** をそれぞれ `Account URL` で巡回
> - **特定キーワード/ハッシュタグ** を `by Keywords` / `by hashtag` で取得
>
> といった代替策を取ります。

### ステップ 3：Cookie を取得する（必須・最初に 1 回）

1. テンプレート一覧から **「Get Twitter Cookies」** を選択。
2. **ユーザー名** 欄に `@elonmusk` のように **@ つきハンドル** を入力
   （ニックネームやメールアドレスではない）。
3. **パスワード** 欄に X のログインパスワードを入力。
4. **保存 → 実行** をクリック。
5. 「クラウド収集」または「ローカル収集」を選択 → Cookie が取得される。

> Octoparse はユーザーのプライバシーデータを保存しないと公式に明記されていますが、
> 共有 PC や他人の管理下にある端末では使用しないでください。

> ⚠️ **既知の問題（2025/05 ユーザー報告）**
> 元記事のコメント欄に「**X は確認コード認証で今は使えないみたい残念**」
> （@aoixxsou, 2025-05-17）という指摘があります。
> X が SMS/メールの確認コードや CAPTCHA を要求するアカウントでは
> `Get Twitter Cookies` が完走しないことがあります。
> その場合は **2 段階認証を一時的にメールベースに切り替える**、
> **手動ログイン後の Cookie をエクスポート/インポート** するなどの
> 回避策を検討してください（後述の「§6 トラブルシューティング」参照）。

### ステップ 4：「Twitter Scraper (by Account URL)」で投稿を取得

1. テンプレート一覧から **「Twitter Scraper (by Account URL)」** を選択。
2. パラメータ画面で **Twitter アカウントの URL** を入力。
   - 例：`https://x.com/Octoparse_Japan`
   - 自分のポストを集める場合は自分のアカウント URL。
3. **実行** ボタンをクリック。

取得できるデータ（記事より）：

- ツイート内容
- 投稿時間
- ユーザー名
- リプライ数
- リツイート数
- いいね数
- 閲覧数

### ステップ 5：ローカル抽出 / クラウド抽出を選択

| 種別 | 速度 | 必要プラン |
|---|---|---|
| **ローカル抽出** | 標準 | 無料プランで OK |
| **クラウド抽出** | 最大 **20 倍** 速い | 有料プラン |

データ量が少なければローカル抽出で十分。
完了まで数分かかります。

### ステップ 6：データのエクスポート

抽出完了後、以下の形式で外部ファイルへエクスポート可能：

- **Excel (.xlsx)** — グラフ・ピボットテーブルで見える化
- **CSV**
- **HTML**
- **JSON**
- **データベース**（MySQL / SQL Server / Oracle 等）

## 4. ハッシュタグ / キーワードからの収集（応用）

ブランドモニタリングや市場調査では Account URL ではなく
キーワード/ハッシュタグ起点の方が便利です。

### 4-1. ハッシュタグから取得

1. テンプレート **「Twitter Scraper (by hashtag)」** を選択。
2. ハッシュタグを入力（例：`#新製品名`）。
3. 取得項目：いいね数、リポスト数、返信数 等。

### 4-2. キーワード + 期間で取得

1. テンプレート **「Twitter Scraper (by Keywords)」** を選択。
2. **キーワード** と **期間** を指定（例：`Octoparse` を 2025-01-01〜2025-03-31）。
3. 期間内に投稿された情報をまとめて取得。

### 4-3. キーワードから作成者情報を取得

1. テンプレート **「Twitter Auteur Scraper」** を選択。
2. キーワードを指定すると、関連投稿の作成者（コンテンツ・コメント含む）を抽出。

## 5. 合法性と倫理 — 必ず守ること

スクレイピング自体は違法ではありませんが、誤った使い方は法的リスクを伴います。
特に X は **公式に API 外のスクレイピングを禁止** しています。

### 5-1. 一般原則

- **著作権の遵守**：保護コンテンツの無断収集・再配布は違法。
- **プライバシー保護**：個人情報の無断収集はプライバシー侵害になり得る。
- **利用規約の遵守**：サイト固有の規約に従う。

### 5-2. X（Twitter）特有の規約

X のサービス利用規約には次の記述があります（参考記事の引用）：

> 「当社の現在利用可能な公開インターフェース以外の方法での、本サービスへの
> アクセスは禁止」
>
> 「クローリングまたはスクレイピングを、当社による事前の書面での同意がない
> まま行うことは明示的に禁止」

つまり厳密に規約遵守したいなら **X API を使うのが唯一の正解** です。
本手順書のスクレイピング方法は、自己責任で **個人の小規模利用** に
限定してください。

### 5-3. 実施時の注意点

- 短時間での大量アクセスを避ける（数分〜数十分単位の間隔）
- 個人的な使用範囲に限定する
- 取得データを再配布・販売しない
- 各サイトの利用規約を事前に確認する
- アカウント凍結のリスクを許容できない用途には使わない

## 6. トラブルシューティング

| 症状 | 原因 / 対処 |
|---|---|
| **Get Twitter Cookies が確認コードで止まる** | 2FA が SMS/Authenticator になっているアカウントでは完走しない。一時的に 2FA OFF、または手動ログイン後の Cookie を手動でインポートする。 |
| **ログインできない / CAPTCHA** | VPN・Proxy を OFF にする。普段使いの IP から実行する。 |
| **0 件しか取れない** | Cookie の有効期限切れ → `Get Twitter Cookies` を再実行。 |
| **取得件数が頭打ち** | X の表示制限。スクロールを増やすか、対象を分割して実行。 |
| **CSV 文字化け** | エクスポート時のエンコーディングを **UTF-8 (BOM 付き)** に変更。 |
| **アカウントに警告/凍結** | 即座に実行頻度を下げる。数日は手動利用のみに留める。 |

## 7. まとめ

- X からの情報収集には **「Web スクレイピングツール」「X API」「OSS」** の 3 択がある。
- 初心者・個人利用には **Octoparse の X 専用テンプレート** が最も手軽。
- 流れは **`Get Twitter Cookies` で認証 → 用途別テンプレートで実行 →
  ローカル/クラウドで抽出 → CSV/Excel/JSON 等でエクスポート**。
- ただし X は規約上スクレイピングを禁止しており、業務利用は
  **X API v2（Basic 以上）への移行** が本筋。
- 2FA・確認コードを使っているアカウントでは `Get Twitter Cookies` が
  動かないことがあるので注意。
